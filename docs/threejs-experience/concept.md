## 1. 一文

**一本の絹糸が、富岡の街と記憶を再構築する。**

スクロールは「ページを送る操作」ではなく、**糸を手繰る操作**である。手繰るほど、暗闇の中に繭・手記・古地図・街・道順が順に現れ、最後に一枚の地図として綴じられる。

## 2. なぜ 3D でなければならないのか

装飾のために 3D を足すのではない。この題材には**奥行きが意味を持つ**理由がある。

| 題材 | 平面では表せないもの | 3D で得られるもの |
| --- | --- | --- |
| 絹糸 | 糸は「奥へ続く」ことで初めて導線になる | カメラが糸に沿って進む＝物語が進む |
| 繭 | 内と外がある構造体 | 半透明の内側に光が生まれる＝記憶が宿る |
| 古地図・手記 | 紙は重なり、反り、光を受ける | 層と質感で「資料である」ことを伝える |
| 富岡の街 | 地図は俯瞰、街歩きは地上 | 俯瞰→地上への視点移動＝実際の体験の予告 |
| 謎解きルート | 順路は時間軸を持つ | スクロール量＝時間軸として直接写像できる |

**判断**: 3D は「かっこいいから」ではなく、**スクロール量を物語の時間軸に変換する装置**として採用する。

## 3. 物語構造（起承転結）

| 幕 | セクション | 内容 | カメラ |
| --- | --- | --- | --- |
| 起 | Hero | 暗闇に糸が現れる | ほぼ静止 → 微前進 |
| 承 | Story | 手記と古地図が空間に開く | 紙の層を通過 |
| 転 | City | 地図から街が立ち上がる | 俯瞰 → 各施設へ寄る |
| 結 | Route / CTA | 道順が引かれ、糸が円environment を閉じる | 引いて全体を見せる |

各セクションを独立したカード群として扱わない。**カメラは一度も切り替わらず、連続して移動する。**

## 4. PC とスマートフォンの違い（同じものを縮小しない）

同じ世界観だが、**目的が違うので設計を分ける**。

| | PC（1024px〜） | スマートフォン（320〜430px） |
| --- | --- | --- |
| 利用文脈 | 自宅・落ち着いて閲覧、参加を検討する | **富岡の街を歩きながら**参照する |
| 主役 | 3D 空間そのもの（映像作品として） | 情報（地図・受付・所要時間） |
| 3D の役割 | 物語を進行させる舞台 | 世界観を保つ最小限の気配 |
| カメラ | 長い連続移動 | 短い、控えめ |
| 粒子 | 多層 | 少数 |
| post-processing | 限定的に可 | **なし** |
| 優先指標 | 没入感・連続性 | 可読性・電池・発熱・地図操作 |

**禁止**: スマートフォンで PC のシーンをそのまま動かすこと。**歩きながら使う端末で発熱させない。**

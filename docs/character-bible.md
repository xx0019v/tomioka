## 0. 前提と安全境界

- 繭標は実在人物・史実上の人物・富岡市の公認キャラクターを表さない。
- 現行サイトの「永山 繭」「明治五年」「百五十年前の研究記録」は、受領済みサイト内の物語設定として参照するのみ。史実として断定しない。
- キャラクターは謎の答え・キーワードの実値・判定条件を話さない。画像名・alt・メタデータ・レイヤー名にも答えを入れない。
- 公式情報（住所・営業時間など）はキャラクターの口調で語らせず、UIの事実表示（詳細パネル／情報ステータス）に委ねる。キャラクターは「確認中である」ことだけを伝える。

## 1. コンセプト

**一文定義:** 富岡に残された絹と記録を知る、小さなカイコの幼虫の「記録案内人」。

- 蚕（カイコ）は富岡製糸場・絹産業・地域の記憶を結ぶ存在。ゆるキャラではなく、物語とUXを導く案内役。
- 子どもには可愛く、大人には静かで上品に見える。一過性の流行に寄せない。
- 装飾ではなく機能：視線誘導・状態通知・不確定情報の丁寧な明示を担う。

## 2. 造形（現行SVG実装に準拠）

実装: `src/components/guide/SilkwormMascot.tsx`（インラインSVG・viewBox 120×120）。
ラスター画像は使わない。理由は §7。

### 2.1 シルエットと比率
- ふっくらした横長の胴（ゆるやかな弧）＋やや大きめの丸い頭。頭身は「幼虫らしい丸み」を優先した控えめなデフォルメ。
- 過度な二頭身化・巨大な目・アニメ的誇張はしない。

### 2.2 恒常モチーフ（全ポーズで維持する同一性ロック）
1. ミルキーホワイト〜生成りの、節のある柔らかな胴（絹の艶をやわらかいグラデで表現）。
2. 尾部の小さな**尾角**（カイコ特有・種の識別要素）。
3. 首元の**桑の葉タグ**（мулberry green / `#5c7148`）。
4. 尾から静かに伸びる一本の**絹糸**（赤煉瓦色 / `#a8402a`）。
5. 小さな脚（幼虫であることの合図）。

### 2.3 顔
- 目は小さな縦楕円＋微細なハイライト。喜び時のみ弧の目。休息／読み込み時は半閉じ。
- 口は基本「点」、喜び／あいさつは小さな弧、注意はへの字寄り。
- 頬は喜び時のみ赤煉瓦を薄く（opacity 0.28）。品よく。

## 4. 表情・状態（実装済み）

`GuideExpression` → 顔の対応（`faceForExpression`）:

| expression | 顔 | 使用状況 |
| --- | --- | --- |
| greeting | smile | 初回あいさつ |
| neutral | calm | 通常・手動オープン |
| pointing | look（視線を寄せる） | 方向案内 |
| map-reading / thinking | down（目を伏せる） | 地図確認・思考 |
| discovery / pleased / clear | happy（弧の目・煌めき） | 発見・到達・クリア |
| concerned / caution | worried（困り眉） | 注意喚起 |
| loading | rest（半閉じ） | 読み込み |

マーカー用途は `simplified` プロパティで葉・糸・煌めきを省き、視認性優先の簡略版にできる。

## 5. モーション規則

- 生命感は「小さく呼吸する」程度（`guide-breathe`）。常時大きく動かさない。
- 発見時のみ一度きりの弾み（`guide-discovery`）。バウンス多用・全要素フェードインは禁止。
- `prefers-reduced-motion` と低速回線（`data-static`）でアニメーション停止。
- エラー時にコミカルに跳ねさせない（信頼を損なう）。

## 6. Web使用寸法・構図

- ヒーロー／マップ上部: 実寸およそ 90–120px。丸い枠＋やわらかな影で接地。
- 吹き出し（FIELD GUIDE）は左、キャラクターは右。台詞は `aria-live`、公式事実はUI側。
- マップマーカーは番号（S/①…）を優先し、キャラクター簡略版は将来の装飾用に温存（番号の方が巡回順の視認性が高いため）。

## 7. なぜSVGか（ラスター生成を採らない理由）

1. 15状態でシルエット・体型・模様の**同一性を保証**（「別キャラ化」を構造的に防止）。
2. 数KBで**屋外・低速回線**に強い。
3. 200%ズーム・任意DPRで**輪郭が崩れない**。
4. ブランド色で**正確に着彩**でき、AI生成特有の不自然さが出ない。

将来ラスターのキービジュアルが必要になった場合も、本SVGを基準シートとして色・比率・モチーフを固定する。

## 8. アクセシビリティ／代替テキスト方針

- キャラクターSVGは装飾として `aria-hidden`。意味は吹き出しテキストが担う。
- 吹き出しは状況に応じ `role=status`／`alert`（`aria-live` polite/assertive）。
- 操作（開閉）はキーボード可、Escで閉じ、フォーカスをトリガーへ戻す。
- 「案内を減らす／戻す」で頻度を利用者が制御できる。

## 10. 禁止事項（要約）

- 白く丸いだけの量産ゆるキャラ化／過剰な幼児デフォルメ。
- 既存キャラクターへの類似造形、無意味な帽子・和装。
- 白・赤・金だけに頼る安易な和風。
- 答え・ヒント・判定に触れる発言。公式事実をキャラ口調で断定。
- 右下固定のチャットボット的な置き方（本実装は状況連動＋利用者制御）。

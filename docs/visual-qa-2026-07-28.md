# 実画面批評と改善ログ

実施日: 2026-07-28（Asia/Tokyo）
対象: ローカルproduction static export

## 評価コンセプト

> The interface feels like an excavated silk archive layered into Tomioka’s
> street soil, expressed through editorial strata, evidence-like type, and
> thread-led discovery.

## Round 0 — 現状確認

確認画面: `docs/qa/baseline-local-mobile.png`

- 台帳、章トレース、2D/3D経路は意味と操作へ接続済みで、均等カード型テンプレートではない。
- 一方、画面全体がほぼ墨緑と罫線だけで、富岡固有の桑、赤煉瓦、土、繭殻が実画面に不足。
- 公開中ページとローカル作業ツリーに差分があり、公開版は現在の操作性修正を含んでいない。

## Round 1 — 環境レイヤー統合

確認画面:

- `docs/qa/round1-mobile-390.png`
- `docs/qa/round1-desktop-1440.png`
- `docs/qa/round1-ledger-desktop-1440.png`
- `docs/qa/round1-route-desktop-1440.png`

実装:

- ヒーローに桑枝を追加し、既存Canvasのポインター値へ連動。
- 台帳へ復元標本を追加し、採録状態で強調できる構造にした。
- 巡回章へ土、苔、根、赤煉瓦、繭殻の背景と地層を追加。
- すべての新規素材をUIより下層に置き、操作面を妨げない構成にした。

批評:

- デスクトップでは桑と地層が世界観を統一した。
- 復元標本は暗すぎ、素材として認識しづらかった。
- モバイルの桑枝はほぼ消え、富岡固有性の補強が弱かった。
- 元画像が史料に見える表記は避ける必要があった。

## Round 2 — 密度・誠実性・狭幅操作

確認画面:

- `docs/qa/final-mobile-390.png`
- `docs/qa/final-desktop-1440.png`
- `docs/qa/final-ledger-desktop-1440.png`
- `docs/qa/final-trace-360.png`

修正:

- モバイル桑枝のopacityとcropを微増し、CTA下の環境層として読める強さへ調整。
- 台帳標本を拡大・明度調整し、本文とリンクの間の「物証」として読めるようにした。
- ヒーロー資料ラベルを `再構成 / MEIJI` に変更し、史料誤認を防止。
- 360/375pxで章カウンターを省き、6操作を全幅へ再配分。
- 位置情報拒否時の案内を現在地ボタンの上段へ移し、凡例との重なりを解消。
- `prefers-reduced-motion` 時はHeroのpointer/scroll listenerを登録せず、JS視差も停止。

実測:

| 条件 | 横overflow | 44px未満の表示中操作 | 補足 |
| --- | ---: | ---: | --- |
| 390×844 | 0 | 0 | ヒーロー、台帳、主要CTAを確認 |
| 360×800 | 0 | 0 | 章リンク6個が各59×56px |
| 1440×1000 | 0 | 0 | ヒーロー、台帳、巡回章を確認 |

## 残る制約

- 初回監査時点では実在地点の許諾済み写真が未提供だったため、架空写真を生成せず、
  プレースホルダーを維持した。その後の2026年7月28日追加制作で許諾確認済み写真へ更新済み。
  現行の出典と条件は[`checkpoint-photo-provenance.md`](checkpoint-photo-provenance.md)を参照。
- 正式な謎、正解hash、判定条件は未提供。架空の正解を追加していない。
- `Save-Data`、WebGL context loss、位置情報拒否はコード分岐と静的状態を確認したが、
  今回のin-app Browserでは環境注入による実演を行っていない。

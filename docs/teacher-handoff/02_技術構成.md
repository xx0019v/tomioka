# 02 技術構成

| 分類 | 実装 |
| --- | --- |
| フレームワーク | Next.js 16.2.11 App Router、`output: "export"` |
| UI | React 19.2.4 |
| 言語 | TypeScript 5、TSX |
| 3D | Three.js 0.185.1。動的import、端末tier別予算、WebGL fallback |
| アニメーション | GSAP 3.15.0 / ScrollTrigger、CSS animation、requestAnimationFrame |
| 地図 | Leaflet 1.9.4、OpenStreetMapタイル |
| スタイル | CSS Modules 20ファイル、共通CSS 1ファイル |
| 画像 | Next Image（静的exportのためunoptimized）、WebP/JPEG/PNG |
| テスト | ESLint、TypeScript、Playwright 1.62.0（Chrome/WebKit） |
| 公開 | GitHub Pages、`/tomioka` base path、`out/`静的出力 |
| パッケージ管理 | npm、package-lock v3 |

## Node.js

Next.jsパッケージのenginesは`node >=20.9.0`です。リポジトリには`.nvmrc`、`.node-version`、`package.json#engines`はありません。提出検証はNode.js 26.4.0で行いました。

## 外部通信

- OpenStreetMap: 地図タイル
- Google Maps: 施設位置を外部地図で開くリンク
- Google Analytics: 測定IDを設定した場合だけ読み込み
- 施設写真の出典ページ: クレジットリンク

独自バックエンド、データベース、認証APIはありません。

## ブラウザ権限

位置情報は利用者が「現在地を表示」を押した場合だけ要求します。拒否しても主要機能は維持されます。カメラ、マイク、通知権限は使用しません。

# 01 起動手順

## 1. ZIPを展開する

ソースZIPをダブルクリックし、`tomioka-source-2026-08-04`フォルダを任意の場所へ置きます。`node_modules`は同梱していません。

## 2. ターミナルを開く

- macOS: アプリケーション → ユーティリティ → ターミナル
- Windows: PowerShellまたはWindows Terminal

## 3. フォルダへ移動する

```bash
cd 展開したフォルダのパス/tomioka-source-2026-08-04
```

フォルダをターミナルへドラッグするとパスを入力できます。

## 4. Node.jsを確認する

```bash
node --version
npm --version
```

Node.js 20.9.0以上が必要です。本提出物はNode.js 26.4.0、npm 11.17.0で検証しています。

## 5. 依存関係をインストールする

```bash
npm ci
```

`package-lock.json`に固定された依存関係が復元されます。

## 6. 開発サーバーを起動する

```bash
npm run dev
```

ブラウザで http://localhost:3000/ を開きます。

## 7. 確認するページ

- トップ: http://localhost:3000/
- 開催情報: http://localhost:3000/information/
- 街歩きマップ: http://localhost:3000/map/

## 8. 停止する

起動中のターミナルで`Control + C`を押します。

## 9. 本番ビルド

```bash
NEXT_PUBLIC_BASE_PATH=/tomioka NEXT_PUBLIC_DEPLOY_ORIGIN=https://xx0019v.github.io npm run build
```

成果物は`out/`に生成されます。`file://`で直接開くとbase pathやJavaScriptが正しく動かないため、HTTPサーバーを使ってください。

```bash
npx serve out
```

GitHub Pagesと同じ`/tomioka`で確認する場合は、公開用ビルドZIPをWebサーバーの`tomioka/`配下へ配置します。

# 04 公開方法

## 現在の構成

- リポジトリ: https://github.com/xx0019v/tomioka
- 公開サイト: https://xx0019v.github.io/tomioka/
- 公開ブランチ: `gh-pages`
- 静的出力先: `out/`
- base path: `/tomioka`

GitHub Pages用ビルドは次の環境で生成します。

```bash
NEXT_PUBLIC_BASE_PATH=/tomioka \
NEXT_PUBLIC_DEPLOY_ORIGIN=https://xx0019v.github.io \
npm run build
```

`public/.nojekyll`は`out/.nojekyll`へコピーされ、GitHub Pagesで`_next`資産が除外されることを防ぎます。`trailingSlash: true`により各ページはディレクトリ形式で出力されます。

## 注意

先生がソースを確認するために再公開する必要はありません。`gh-pages`を更新すると本番サイトを上書きするため、管理者の明示的な判断なしにpushしないでください。本提出作業では`main`、`gh-pages`、本番公開を変更していません。

正式案内URL https://mayu-no-chizu.cid-ac.com/ は別配信元です。ソースのcanonicalと案内リンクは正式URLを指しますが、正式URL側の更新には別ホスティングの権限が必要です。

# 05 素材とライセンス

## 自作素材

- UI、CSS、地図ピン、絹糸、方眼・紙テクスチャ
- Three.jsの街・繭・糸・粒子・CanvasTexture
- React内のSVGキャラクター、方位記号、装飾図版
- 文章、開催情報の構造、コンポーネント実装

アイコン専用ライブラリは使用せず、CSS、文字記号、自作SVGで構成しています。

## 生成・再構成素材

- `public/images/artifacts/`、`public/images/environment/`などは、実在地点と誤認させない装飾・環境素材として生成・再構成されています。生成記録は`docs/environment-asset-log.md`にあります。
- `assets/character/*.png`は画像生成後に背景除去した制作用マスターです。公開UIの主要キャラクターはReact内の自作SVGです。
- キャラクターマスターの画像生成サービスに関する商用利用条件・生成履歴メタデータは、この監査では独立確認できていません。マスターは制作資料であり、先生による再配布時には条件の再確認を推奨します。

## フォント

Webフォントファイルは同梱していません。OS標準のヒラギノ、游明朝、游ゴシックを優先し、端末に存在する場合はNoto Serif JP / Noto Sans JPへフォールバックします。

- Leaflet: BSD-2-Clause

- Google Maps: 外部検索リンクのみ。地図データを同梱していません。

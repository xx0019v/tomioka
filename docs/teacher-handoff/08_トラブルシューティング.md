# 08 トラブルシューティング

## `npm ci`が失敗する

Node.js 20.9.0以上か確認し、ZIP内の`package-lock.json`を削除・編集せずに実行してください。`npm install`ではなく`npm ci`を使います。

## Node.jsバージョンが違う

```bash
node --version
```

20.9.0未満ならNode.js公式サイトまたはバージョン管理ツールで更新します。

## 画像が表示されない

`file://`でHTMLを直接開かず、`npm run dev`またはHTTPサーバーを使用します。GitHub Pages用ビルドは`/tomioka`配下へ置きます。

## GitHub Pagesでパスが壊れる

```bash
NEXT_PUBLIC_BASE_PATH=/tomioka NEXT_PUBLIC_DEPLOY_ORIGIN=https://xx0019v.github.io npm run build
```

`out/.nojekyll`と`out/_next/`が存在することを確認します。

## WebGLが動かない

ブラウザのハードウェアアクセラレーション、WebGL対応を確認します。WebGL不可、reduced-motion、Save-Data、低性能判定時は静的表示へ切り替わる設計です。

## 地図が操作できない

ネットワーク接続とOpenStreetMapタイルへの接続を確認します。モバイルでは最初に「地図を操作」を押します。位置情報を拒否しても一覧から施設を選択できます。

## ポート3000が使用中

```bash
npm run dev -- --port 3001
```

ブラウザで http://localhost:3001/ を開きます。

## ビルドに失敗する

1. `node --version`を確認
2. 展開直後のソースで`npm ci`
3. `npm run typecheck`
4. `npm run lint`
5. `npm run build`

エラー全文とNode/npmバージョンを記録してください。秘密値を含む`.env.local`は共有しないでください。

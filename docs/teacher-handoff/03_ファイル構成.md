# 03 ファイル構成

```text
src/
  app/                 ページ、レイアウト、メタデータ、CSS
  components/
    arrival/           お富ちゃん家・駅から入口まで
    guide/             案内キャラクター
    immersive/         絹糸、Three.js、スクロール演出
    map/               Leaflet地図とスポット詳細
    site/              ヘッダー、フッター、共有UI
  data/                開催情報、施設、座標
  lib/                 base path、端末tier、分析
public/                公開画像、施設写真、.nojekyll
assets/                制作用マスター画像
e2e/                   Playwright受け入れテスト
scripts/               QA集計スクリプト
docs/teacher-handoff/  本資料
```

## 主要ファイル

- `next.config.ts`: 静的export、base path、末尾スラッシュ、画像設定
- `package.json` / `package-lock.json`: コマンドと依存関係
- `src/app/page.tsx`: トップページ
- `src/app/information/page.tsx`: 開催情報
- `src/app/map/page.tsx`: 地図ページ
- `src/components/map/EventAreaMap.tsx`: 地図・位置情報・詳細パネル
- `src/components/immersive/SilkCityScene.tsx`: Three.js街形成演出
- `src/components/immersive/SilkTrail.tsx`: ページ全体の絹糸導線
- `src/data/site.ts`: 正式URL、開催日、受付地点
- `src/data/spots.ts`: 6施設の表示・座標・出典
- `e2e/teacher-feedback.spec.mjs`: 教員指摘6項目の回帰テスト

## 操作安全性

- 回答送信と現在地取得に同期ロックを追加し、再描画前の二重実行を防止。
- 3D読み込み中は切替ボタンを無効化。
- 地点一覧から詳細を開いた場合、閉じた後は元の一覧ボタンへフォーカスを復帰。
- 回答フォームへ `aria-busy` / `aria-invalid` を追加。
- ヒント開閉へ `aria-controls` を追加。
- Canvas内3D地点へ透明な拡張hit meshを追加。
- disabled中はpointer eventを受け付けない。

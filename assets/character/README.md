# GUIDE-01 asset notes

「繭標（まゆしるべ）」は仮称・仮設定です。正式名称、運営承認、類似意匠・商標、公開範囲を確認するまでは、公認キャラクターとして扱いません。

## Masters

- `guide-01-neutral-master.png` — 基準正面3/4
- `guide-01-thinking-master.png` — 確認中・考える状態
- `guide-01-discovery-master.png` — 発見・進行更新状態

いずれも 1254×1254px、RGBA、透過PNGです。画像生成時のクロマ背景を除去し、マスターは再編集用として保持しています。

## Web derivatives

`public/images/guide/` の320×320px透過PNGを配信に使用します。台詞、地点名、謎の答えは画像へ焼き込まず、DOMテキストで提供します。

生成プロンプト、同一性ロック、禁止事項、状態差分は `docs/character-bible.md` を参照してください。
